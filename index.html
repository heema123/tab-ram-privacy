Tab RAM Privacy Policy

Tab RAM does not collect, store, transmit or sell any personal data. Everything it does happens inside your browser.

What the extension does

Tab RAM shows an estimate of how much memory each open tab is using and lets you free, lock or close tabs. It can also free idle tabs on a schedule if you turn that on.

Data collected

None. The extension has no servers, makes no network requests, and contains no analytics, advertising or tracking code.

What the extension reads, and why

  • Tab titles, URLs and state (pinned, playing audio, already freed) are read to draw the list in the popup and to decide which tabs are safe to free. They are shown to you and discarded when the popup closes.
  • Page memory signals: a small read-only script runs in each open tab to count DOM elements, images and media and to read the page's JavaScript heap size. It never reads page text, form contents, cookies or anything you type.
  • System memory (free and total RAM) is read to show a summary line and, optionally, to run cleanup only under memory pressure.

Data stored on your device

Your settings (auto-mode, thresholds, protected domains) are stored in Chrome's extension storage on your computer. Tab locks are kept only for the current browser session. Nothing is synced or uploaded by the extension.

Permissions

The extension requests tabs, scripting, storage, alarms, system.memory, favicon and access to all sites. Site access exists only so the memory probe can run on whatever pages you have open. On Chrome Dev and Canary the processes permission provides exact per-process figures; on Chrome stable it is unused.

Third parties

No data is shared with anyone, because no data leaves your browser.
